# WP Credits Welcome Plugin

A simple WordPress plugin created for the WP Credits
Developer Basics Git assignment.

## Features

- Displays a welcome message using a shortcode.
- Supports a custom visitor name.
- Supports a custom message.
- Escapes user-provided text for safe display.

## Installation

1. Download the plugin folder.
2. Place it inside `wp-content/plugins/`.
3. Open the WordPress admin dashboard.
4. Go to Plugins and activate WP Credits Welcome.

## Usage

Add this shortcode to a WordPress page:

[wp_credits_welcome]

To customize the name:

[wp_credits_welcome name="Solehjon"]

To customize the message:

[wp_credits_welcome name="Solehjon" message="Enjoy my website!"]
